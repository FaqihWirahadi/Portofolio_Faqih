WEBSITE PORTOFOLIO — MUHAMMAD FAQIH

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder website_portofolio_faqih.
3. Klik dua kali index.html atau buka menggunakan browser.
4. Tidak memerlukan database, instalasi, atau server untuk tampilan statis ini.

SEBELUM DIPUBLIKASIKAN
- Ganti emailkamu@example.com dengan email aktif.
- Ganti tautan GitHub dan LinkedIn yang masih berupa #.
- Tambahkan foto profil pada bagian avatar (opsional); sesuaikan HTML/CSS.
- Tambahkan tautan demo, repository, dan screenshot asli proyek.
- Periksa kembali daftar skill dan deskripsi proyek agar sesuai kemampuan aktual.

STRUKTUR
index.html  : konten website
style.css   : desain, layout, dan responsive
script.js   : menu mobile, animasi scroll, tahun otomatis

Catatan: Google Fonts memerlukan koneksi internet. Jika offline, website menggunakan font cadangan dari sistem.
